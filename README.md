# Open GovTech Index domain redirect

HTTPS landing page for `govtechindex.cloud`, forwarding browsers to the live Index at `https://www.govtechindex.cloud/` while retaining the requested path, query and hash route. Hosted on free GitHub Pages. The www site, REST and MCP API are hosted on Hugging Face.

Source application: https://github.com/AndreasThinks/open-govtech-report
